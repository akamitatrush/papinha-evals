Por que este domínio

Quando o produto de IA erra, o custo não é uma resposta ruim

A partir dos 6 meses começa a introdução alimentar. Errar aqui é botulismo (mel antes de 1 ano), asfixia (uva inteira tem o diâmetro exato da traqueia infantil) ou anafilaxia. É um domínio onde a falha crítica é objetivamente verificável — não é questão de gosto se mel antes de 1 ano é errado.

Isso permite detectores determinísticos de alta precisão para a camada de segurança, e reserva o LLM-como-juiz para o que é genuinamente interpretativo: se “amassado com pedaços macios” é adequado aos 8 meses, se uma restrição declarada como “APLV” foi respeitada quando a receita pede requeijão.

A armadilha central

Quanto melhor o bot fica, mais o detector acusa

"mel" in texto acusa melão, melancia e caramelo. "sal" acusa salada, salsinha e salmão. Isso se resolve com fronteira de palavra. O problema seguinte não.

resposta correta do bot · acusada como falha
“Não use mel — é contraindicado antes de 1 ano por risco de botulismo.”
O bot está certo. O detector conta a palavra e reprova. Quanto mais o bot melhora em segurança, mais ele fala sobre alimentos proibidos — e mais a métrica piora. O número anda para trás enquanto o produto melhora.

A correção não foi remendar caso a caso. Foi mudar a pergunta: o modo de falha nunca foi “o bot mencionou mel”, é “o bot recomendou mel”. A distinção, em português, é morfológica — “Use mel” é imperativo e instrui; “Adicionar sal pode mascarar sabores” é infinitivo-sujeito e explica.

O que este projeto ainda não provou

As ressalvas fazem parte do resultado

O auditor automático não está validado

O pipeline usa um LLM para decidir se cada achado procede. Ele é, ele próprio, um juiz não medido — e nos testes classificou o mesmo achado de formas diferentes em execuções distintas. Automatizar o julgamento não elimina a validação humana: move ela de toda rodada para uma vez.

33 traces não são 100

A meta de análise de erros é ~100 traces, onde novos casos param de revelar tipos novos de falha. Três modos da taxonomia — restrição declarada, contexto multiturno e bajulação sob pressão — não têm ocorrência ainda, então seus avaliadores não têm dados para ser validados.

Prevalência é estimativa, gravidade não

O eixo de gravidade vem de diretriz publicada. O de prevalência vem de uma amostra pequena. Priorização feita sobre os dois deve tratar o segundo como provisório.
